# ScriptLinkRx Dashboard

React 18 application using Vite and Tailwind CSS.

## Development

```sh
pnpm install
pnpm dev
```

Open http://localhost:5173/Dashboard/.

## Production build

```sh
pnpm build
pnpm preview
```

The app retains the original `/Dashboard/` base path.

Migrated the active app, product data, imported assets, styles, and favicon. Unused components, design exports, image-generation scripts, mockup outputs, email-signature projects, and repository history were omitted. The source project was preserved.
