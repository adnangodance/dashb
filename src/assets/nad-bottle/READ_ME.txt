NAD+ BOTTLE — FILES ONLY

Upload this entire ZIP to Codex when adding the bottle to your existing site.

NAD_Bottle.glb — the 3D bottle, with the improved side glass and a smooth recessed circular base. All current textures are embedded.
Label_EDITABLE.svg — an editable label. Product title, subtitle and strength are real text, and its fonts are embedded.
title-strength.json — the current text values in one easy-to-edit file.

The GLB keeps the current NAD+ / INJECTION / 200 MG/ML appearance. A GLB does not contain native editable text. For a change, ask Codex to edit the SVG text or the JSON values, render the SVG as a 2360 × 2944 texture, and apply that texture ONLY to the material named "Editable product label". Do not replace the original shared cap photograph. Keep the existing UV mapping. For a Three.js integration, use an sRGB texture with flipY=false. The title and strength can then be controlled by your existing site's product settings if Codex connects those settings to this label.

Suggested instruction to Codex:
"Use the attached 3D bottle on my existing site. Make the label title and strength editable using Label_EDITABLE.svg and title-strength.json. Preserve the glass, cap and label positioning."

Model scale: approximately 62 mm tall; no measured manufacturing dimensions were supplied. The user's Meshy bottle was used as the base. The bottom was rebuilt with a smooth circular rim. Front/rear glass details and the silver cap include fixed photographic reflections; the sides and underside use physical glass. Exact appearance depends on the site's lighting and renderer.

The reference photo supplies the current cap and label artwork. A clean glass reference and paper texture were generated using the built-in image-generation tool. Font licenses are included; Anton and Barlow Condensed come from https://github.com/google/fonts/tree/main/ofl/anton and https://github.com/google/fonts/tree/main/ofl/barlowcondensed.

This package contains no website and does not publish anything.
