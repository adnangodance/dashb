# ScriptLinkRx landing page

Native React implementation of https://scriptlinkrx.com/, captured September 25, 2026.

- Open `?view=landing` on the app's base URL, or use the homepage link on the existing login screen.
- Log in, Register, Request a demo, and View Catalog open the existing app screens. Direct links also accept `?view=login`, `?view=register`, `?view=request-demo`, `?view=sales-catalog`, `?view=sales`, and `?view=w9`.
- The hero pairs PP Mori typography with a decorative HTML/CSS order workspace, a compact facts strip and an overlapping pharmacy network card using existing dashboard logos. Desktop uses two columns; tablet stacks the content; below 768px the headline, supporting copy, full-width 52px CTAs and trust line precede a three-row preview. The pale gradient, faint CSS grid and soft radial wash replace the former vial artwork and dotted arc. Hero and header buttons retain the existing deep-blue action color. Entrance animations and perspective are disabled for reduced motion. The mobile navigation drawer and sticky conversion bar retain their existing behavior; the partner panel below retains its logo strip and facts row.
- PP Mori Semibold and Inter Display (Regular/Medium) are bundled from the user-provided reference's `/fonts/` assets. Navigation matches its Inter Display Medium styling: 16px on wide screens, 14px on smaller desktop screens, with 0.1px tracking. The hero and partner panel use Inter Display for supporting text; lower sections retain the existing local Inter font.
- The pharmacy logo strip pauses on hover or keyboard focus, and stops while offscreen or in a hidden tab. Reduced-motion users get a manually scrollable row instead.
- The pharmacy network section is a compact white logo strip with a centered “Trusted by” heading and a small ownership disclaimer. Logos sit directly on the page, without a surrounding card, introduction, or statistics. The hero's bottom margin is removed to eliminate the striped seam above it.
- Original public images, logos, and fonts are stored in `src/assets/landing-reference`. CSS is scoped to this page.
- The 503A / 503B section highlights patient-specific prescriptions and office-use supply. Copy follows the FDA's distinction: https://www.fda.gov/drugs/human-drug-compounding/human-drug-compounding-laws.
- The order journey and formulation carousel advance every two seconds while visible, pause during interaction, and respect reduced motion. Testimonial controls and horizontal specialty rails support manual navigation.
- `partners.json` and `coverage-map.json` are snapshots of the site's public pharmacy directory and licensed-state data. The public directory contains 16 pharmacies, of which 15 have logos. Coverage geometry uses the reference site's US Atlas projection, with a tighter display viewBox to reduce empty margins. No signed download URLs or credentials are stored.
- Account forms and catalog access retain the dashboard's existing demo behavior; this page does not add authentication or a live pharmacy-data service.

Refresh the directory and coverage snapshots when production data changes. Source data: `https://api.scriptlinkrx.com/business-partners`, `https://api.scriptlinkrx.com/business-partner-licensed-states`, and `https://cdn.jsdelivr.net/npm/us-atlas@3/states-10m.json`.

The 503A / 503B products section and the order journey each have a light background panel that expands from inset rounded corners to full width as it enters the viewport, inspired by the testimonial entrance at https://nacew.vercel.app/#testimonials. Other sections do not use this animation. The footer retains its dark artwork. `LandingSection` measures an untransformed wrapper, batches scroll updates in one animation frame, uses gentler scaling on mobile, and disables motion for reduced-motion preferences. Run `node --experimental-strip-types --test tests/section-motion.test.ts` to check the scroll progression.

`OrderJourney` uses Geist typography and black headings, neutral supporting text, a pale illustration card, and a white timeline card. The active step has a soft gray background and black icon. The illustration card contains only a soft azure image, title, and description, without badges, counters, decorative rings, or progress controls. Its five selectable timeline steps stay synchronized with the existing illustrations and descriptions; the animation pauses on hover or keyboard focus and respects reduced-motion preferences. The section shares the products section’s scroll-expansion effect and keeps its own pale background.

`PlatformComparison` retains the original side-by-side white panel with a small central divider and “vs” label. It uses paired comparison rows, PP Mori headings, muted old-workflow icons, and indigo checks. The comparison stays static; it does not use the scroll-expansion effect.

Section headings are centered. The certification strip retains its original full-width banner layout and logo colors, using the same glacier-blue / seafoam gradient as the 503A / 503B products section. Coverage sits directly on the white page, with solid blue tones showing pharmacy density, blue hover and selection states, readable state labels, and a frosted-glass partner detail panel with subtle row dividers and a close control. The panel falls back to an opaque pale-blue surface when backdrop blur is unavailable. Product categories use plain 503A / 503B text labels, and the 503B “for your practice” subtitle uses #38192a, sampled from the supplied burgundy vial label.
